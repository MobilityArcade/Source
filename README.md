FLASH DANZE V13 — STILL-IMAGE WORLDS

INSTALLATION
1. Unzip this package.
2. In your website project, replace index.html, style.css, igusta.js, cinematic-worlds.js and all other included JS files with the versions in this package.
3. Upload the entire worlds/ directory, including all JPG images.
4. Deploy and hard-refresh the browser (Cmd+Shift+R). If your host caches files, redeploy or clear cache.
5. Keep your hosting domain, project settings, analytics, and any other files not included in this ZIP.

WHAT CHANGED
- Ten scenic options use REAL RASTER STILL IMAGES as CSS background-image layers rather than simplified SVG/code-drawn landscapes.
- Existing countdown, gameplay, duration options, progress bar, controls, word styling, language and audio logic are preserved from V12.
- Original neon/effect backgrounds remain available.
- Image scenery has no baked-in movement words or timer. Those remain live HTML overlays.

ARTWORK NOTE
This is a working still-image implementation using crops of the approved concept board, plus the supplied Halloween reference screenshot. Some scenic thumbnails are small and were enlarged, so they will not have the sharpness of original high-resolution artwork. For production, replace worlds/*.jpg with licensed or original full-resolution still images of the same filenames. No rights to third-party photos are implied by this prototype. For best quality use 1920x1080 or larger, with a clear central area for movement words.
