# FLASH DANZE V11 — SCENIC ARCADE

Based on FLASH_DANZE_V10_1_GRID_CHAOS. Retains existing movement words, timing, language, and game controls.

## Installation
Upload / replace all files in this ZIP in the same directory as your live index.html. **Do not upload only index.html**: the new scripts and CSS are required. Keep filenames unchanged. Refresh the page (hard reload if the browser caches old scripts).

## What's new
- Existing Neon Burst and Retro Arcade Grid remain. Also retains the other original effects.
- Seven new procedural animated scenic stages: Neon City / Cityscape, Future Garden, Neon Temple, Dance Club, Neon Studio, Urban Playground, Neon Sunset. These are *original canvas approximations*, not pixel-identical artwork from the pitch-board illustration.
- Seven font treatments: Bold, Outline, Graffiti, Chrome, Pixel, Brush, Futuristic, plus Mix (random choice per cue). These are CSS-based visual approximations, not custom licensed font artwork.
- Word-specific punch, shake, spin, flow, freeze effects and scenic lighting pulses.
- Menu navigate/confirm/start/finish synthesized arcade audio, respecting the Sound Effects switch. No music included.
