BERTIE BERT MOVES — KIDS / GREEN SCREEN EDITION

QUICK START
Open index.html in a browser, or upload all four files together to your web host.
Keep these four files in the same folder:
  index.html
  style.css
  game.js
  words.js

HOW IT WORKS
Choose tempo and duration, then START. A 3-2-1-GO audio/visual countdown begins.
Gameplay is solid #00FF00 with only a white movement cue above a white progress bar.
Tap anywhere during play to pause or resume (the word PAUSED appears temporarily).
At the end, choose TRY AGAIN or HOME.
The existing durations (30 sec, 1, 2, 3, 4, 5, 10, 15 min) and tempo timing
(1.3, 2.6, 4, 6 seconds plus Mixed) are preserved.

VOCABULARY
72 simple English prompts; Spanish translations retained as source data for possible future use.
English only in the minimal interface, to avoid adding another setting.
Some younger children may need a grown-up to read cues; this is not a literacy assessment.

SOUND
The original soundscape.js was NOT provided. This build includes lightweight synthesized
countdown, start, halfway, and finish tones. They are not the exact original sound effects.
If you provide soundscape.js later, the original audio can be reconnected.
Audio may be blocked until START is tapped, per browser policy.

KEEP / REPLACE
KEEP these four NEW files. Replace the old index.html, style.css, igusta.js and words.js
with this new four-file set. The old igusta.js is replaced by game.js.

REMOVE FROM THIS MINIMAL BUILD
Old ui-feedback.js, still-worlds.js, scenic/background image files, neon/canvas effects,
font/color pickers, background settings, logo assets, and other visual scripts are not used.
Old soundscape.js is not required by this build.
Archive old files before deleting them from your live site. If other pages use those assets,
keep them there; removal guidance applies only to this standalone game.

NOTES
Green is the full-screen background on all pages. The setup and finish panels use dark
contrasting cards so that children can read/select controls; gameplay itself has no panel.
No visible timer or logo. No gameplay buttons. The white progress bar fills over time.
No external libraries or network calls required.
