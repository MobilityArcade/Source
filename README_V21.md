# FLASH DANZE V21 — 14 STATIC WORLDS

Upload **all files and folders** from this ZIP to the website root, replacing the previous Flash Danze files. Keep the `worlds/` and `audio/` folders intact.

Includes 14 selectable still-artwork worlds. The first four are retained from V20. Ten new worlds are added: Graffiti Warehouse, Video Game Arcade, Beach Boardwalk, Vintage Asian Temple, Spooky Funhouse, Northern Lights Wonderland, Western Saloon, Mega Stadium, Mega Yacht, Skyline Helipad.

No animated lighting, particles, fog or background effects. Gameplay, layout, fonts, colors and race countdown/halfway/finish audio retained from V20.

Source new artwork is 1663×946 pixels (except original four); WebP compression preserves image dimensions. These are not native 4K sources. Full-screen cover cropping may occur on portrait phones.
